<h1 align="center">📚 Formulario de Calificación de Estudiantes</h1>

<p align="center">
Aplicación en <strong>C# Windows Forms</strong> para registrar notas, calcular el promedio
y determinar si el estudiante aprueba, va a completivo o extraordinario.
</p>

<hr>

<h3>✨ Funcionalidades</h3>
<ul>
  <li>Ingreso de 4 calificaciones</li>
  <li>Cálculo automático del promedio</li>
  <li>Activación de completivo (≤ 69)</li>
  <li>Evaluación de extraordinario</li>
</ul>

<h3>🛠️ Tecnologías</h3>
<ul>
  <li>C# (.NET Framework)</li>
  <li>Windows Forms</li>
  <li>Visual Studio</li>
</ul>
